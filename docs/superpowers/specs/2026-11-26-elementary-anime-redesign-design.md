# 초등학생용 일본 애니메이션(열혈 소년만화·아케이드) 스타일 일본어 학습 앱 설계서

**작성일**: 2026-11-26  
**대상**: 초등학생 (한자 배제, 히라가나·카타카나 중심)  
**비주얼 테마**: 열혈 소년만화 · 아케이드 도장(道場) 스타일  
**접근 방식**: 무의존성 Vanilla HTML/CSS/JS SPA 유지 + Parametric SVG 마스코트/스탬프 + Web Speech API

---

## 1. 아키텍처 접근법 및 범위

### 선택 방식: 무의존성 Vanilla SPA + Parametric SVG
- **유지**: 프레임워크/빌드 도구 없이 `index.html`에서 순수 CSS + IIFE 모듈 JS를 로드하는 경량 구조 유지.
- **정리**: 루트 디렉토리에 방치된 중복 파일(`app.js`, `data.js`, `kana.js`, `quiz.js`, `router.js`, `storage.js`, `words.js`, `variables.css`) 제거 후 `css/`, `js/` 단일 소스로 통일.
- **확장**:
  - `js/svg.js`: Parametric SVG 생성기 (마스코트 캐릭터 3표정, 도장/배지, 집중선, 별 아이콘).
  - `js/speech.js`: Web Speech API(`ja-JP`) 발음 재생 및 브라우저 미지원 시 graceful fallback.
  - `js/progress.js`: `#progress` 스티커북·전적 대시보드 분리.

## 2. 비주얼 디자인 시스템 (열혈 소년만화 · 아케이드)

### 타이포그래피
- **한글 타이틀/HUD**: `Do Hyeon` (굵고 역동적인 만화·아케이드 타이틀감)
- **한글 본문**: `Noto Sans KR`
- **일본어(가나/단어)**: `M PLUS Rounded 1c` + `Noto Sans JP` (초등학생이 획을 쉽게 구분할 수 있는 둥글고 선명한 고딕)

### 컬러 팔레트 & 만화 지면 질감 (`css/variables.css`)
- **배경**: 따뜻한 만화 지면 `#FFFDF5` + CSS 하프톤(망점) 도트 패턴
- **잉크 테두리 & 하드 섀도우**: `#1E1B2E` (2.5px~3px 실선 + `4px 4px 0 #1E1B2E` 하드 오프셋 그림자)
- **히라가나 / 메인 액션**: 일렉트릭 블루 `#2563EB`
- **카타카나 / 라이벌 액션**: 버밀리온 레드 `#E11D48`
- **별·콤보·레벨업**: 아케이드 골드 `#FACC15` (전경 텍스트 `#1E1B2E`로 고대비 확보)
- **정답 / 오답**: 에메랄드 `#10B981` / 코랄 `#EF4444`

### 아케이드·만화 연출 요소
- **마스코트 & 말풍선**: 오리지널 시바견 닌자 마스코트(SVG)가 기본/기쁨/격려 3가지 표정으로 응원 대사 출력.
- **콤보 배틀 HUD**: 퀴즈 화면 상단에 진행 게이지 + 연속 정답 `COMBO!` 배지 + 집중선(Speed Lines) 플래시.
- **마이크로 인터랙션**: 버튼 클릭 시 그림자가 줄며 눌리는 아케이드 버튼 프레스 효과 (`prefers-reduced-motion` 존중).

## 3. 초등학생 맞춤 학습 데이터 (`js/data.js`)

한자 배제 원칙(모든 단어는 히라가나·카타카나 표기)을 지키면서 성인 여행 카테고리를 **초등학생 친화 7개 카테고리 (총 100단어)**로 재구성한다.

| 키 | 카테고리명 | 단어 수 | 예시 단어 |
|----|-----------|--------|-----------|
| `basic_greeting` | 인사와 예절 | 10 | おはよう, ありがとう, ごめんなさい |
| `basic_school` | 학교와 교실 | 15 | がっこう, せんせい, えんぴつ, ノート |
| `basic_animals` | 동물과 자연 | 15 | いぬ, ねこ, うさぎ, パンダ, そら |
| `basic_food` | 맛있는 간식·음식 | 15 | りんご, いちご, おにぎり, ケーキ |
| `basic_family` | 가족과 친구 | 10 | おかあさん, おとうさん, ともだち |
| `basic_action` | 놀이와 움직임 | 20 | あそぶ, はしる, ゲーム, サッカー |
| `basic_color_adj` | 색깔과 기분 | 15 | あかい, あおい, たのしい, かっこいい |

- **가나 데이터 보완**: `KATAKANA`에 요음 7행(`キャ행` ~ `リャ행`) 추가하여 히라가나(22행)와 대칭 구성(각 22행).

## 4. 핵심 기능 명세 및 버그 수정

### 4.1 라우터 & 라이프사이클 (`js/router.js`)
- `Router.onCleanup(fn)` 도입: 해시 변경 시 이전 화면의 `AbortController` 및 대기 중인 `setTimeout` 자동 취소 (리스너 누적 및 화면 덮어쓰기 버그 해결).
- `#kana-quiz` → `#kana`, `#words-quiz` → `#words` 상단 네비게이션 active 유지.
- 모든 인라인 `onclick` 제거 후 이벤트 위임으로 통합.

### 4.2 퀴즈 엔진 (`js/quiz.js`)
- **오답 재출제 정상화**: `start()` 시 10문제를 미리 생성하지 않고, `next()` 시점에 `_dequeue()`를 동적으로 호출하여 `retryQueue`(최대 3회)가 실제 현재 세트 안에서 출제되도록 수정.
- **4지선다 보장**: 선택 풀 크기가 4 미만일 경우 `fallbackPool`에서 중복 없는 오답 보기를 보충.
- **동음이의 처리**: `じ`/`ぢ`, `ず`/`づ` 등 동일 로마자 문자가 한 세트 보기에 중복 출제되지 않도록 필터링.
- **콤보 추적**: 현재 콤보(`streak`), 최고 콤보(`maxStreak`), 문제별 원본 행(`row`) 전달.
- **퀴즈 방향 선택**: 가나 퀴즈에서 `가나 → 로마자` / `로마자 → 가나` 모드 전환 지원.
- **단어 퀴즈 힌트 개선**: 로마자 힌트는 기본 비노출하고 `[발음 힌트 보기]` 토글 버튼 또는 정답 선택 후 피드백 배너에 표시.

### 4.3 저장소 및 보상 시스템 (`js/storage.js`)
- `load()` 시 매번 새로운 기본 객체 복사본 반환 (`_default` 변이 버그 해결).
- 가나 통계는 조합 문자열이 아닌 **개별 행 키**(`"あ행"`, `"か행"` 등)별로 누적.
- 게이미피케이션 필드 추가:
  - `stars`: 누적 별 (퀴즈 정답·세트 완주 시 획득)
  - `bestCombo`: 역대 최고 콤보
  - `stamps`: 해금된 스탬프 ID 배열 (예: `first_quiz`, `combo_5`, `kana_row_clear`, `words_50`, `bookmark_user` 등)

### 4.4 음성 발음 (`js/speech.js`)
- 카드 학습 앞면/뒷면, 단어 퀴즈 정답 피드백, 북마크 단어장에 🔊 `듣기` 버튼 제공 (`window.speechSynthesis`, `lang = 'ja-JP'`).
- 브라우저 미지원 환경에서는 버튼 비활성화 및 안내 텍스트 표시.

### 4.5 학습 현황 스티커북 (`#progress`, `js/progress.js`)
- **도전자 프로필 배너**: 현재 레벨/칭호(예: `Lv.1 아기 시바` → `Lv.5 전설의 가나 닌자`), 누적 별, 최고 콤보.
- **참 잘했어요 스탬프북**: 조건별 SVG 도장 컬렉션 (미해금은 실루엣 + 해금 힌트).
- **행별·카테고리별 정답률 게이지**: 히라가나/카타카나(청음·탁음·반탁음·요음 그룹별) 및 단어 7개 카테고리 정답률 바.
- **내 북마크 단어장**: 북마크한 단어 발음 듣기, 해제, **북마크 단어만 모아서 카드 복습 / 퀴즈 풀기** 기능.
- **기록 초기화**: 만화풍 커스텀 확인 모달을 통한 안전한 리셋.

### 4.6 키보드 & 모바일 접근성
- 카드 학습: `Space`/`Enter`(뒤집기), `←`/`→`(이전/다음), `S`(발음 듣기), `B`(북마크).
- 퀴즈: 숫자키 `1`~`4` 보기 선택.
- 모달/오버레이: `Esc` 및 배경 클릭 닫기, 명확한 포커스 아웃라인.
- 모바일(375px+)에서도 큰 터치 영역(최소 48px 이상) 확보.
